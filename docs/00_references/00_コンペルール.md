# コンペ当日ルール

## 当日のプログラム

- 9:00〜9:30：受付・朝食
- 9:30〜10:00：開会式・チーム自己紹介
- 10:00〜10:15：開発準備
- 10:15〜15:30：企画・開発タイム（昼食・OpenAI メンター相談タイムを含む）
- 15:30：プロジェクト提出期限
- 16:00〜17:00：参加者投票・審査
- 17:00〜18:15：上位4チームによる最終プレゼン・表彰式
- 18:15〜20:30：ネットワーキング・ディナー
- 21:00：イベント終了

## 事前準備・当日の開発

- 参加確定後は、応募時に提出したアイデアをもとに、技術検証、仕様検討、プロトタイプ制作などの準備を進めてよい。
- 事前準備・事前開発は必須ではなく、当日の企画・開発タイムから取り組んでもよい。
- 既存の研究テーマや過去の制作物を参考にしてよい。ただし、今回の応募をきっかけに生まれたアイデアと、当日にCodexを活用して発展させるプロセスが重視される。
- 準備の例として、リポジトリの用意、Issue分割、イメージ画像の作成、プロジェクトドキュメントの作成がある。

## ツール・素材・権利

- 重要な既存コード、OSS、データセット、第三者ツールを組み込む場合は、適用ライセンスとともに提出前に書面で開示する。
- 提出物は独自作成またはパブリックドメインでなければならない。既存のコードや素材を利用する場合も、上記の開示・ライセンス条件を満たすこと。

## 提出・ピッチ・審査

- 15:30までにプロジェクトを提出する。
- 提出物、ピッチ、デモを用意する。
- 決勝では、Codexの効果的な活用、実世界へのインパクト、再利用・展開可能性、デモとピッチの質の4項目を各25%で評価する。
- 一次審査では、同じ4項目を各20%で評価し、参加者投票を20%加味する。参加者は他の1チームに投票し、自分のチームには投票できない。
