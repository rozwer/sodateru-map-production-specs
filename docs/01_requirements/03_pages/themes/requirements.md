# 自分のテーマの機能要件

## 目的

体験を自分のテーマにまとめる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| themes-F01 | テーマを読む | テーマ名・写真・所属記録数を確認できる。 |
| themes-F02 | テーマを作る | 新しいテーマを命名して記録をまとめられる。 |
| themes-F03 | テーマで歩く | 選んだテーマの記録を地図で見られる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 本人が命名したテーマと所属記録を保存し、同じ記録の複数テーマ所属を許す。選択テーマの記録を地図へ渡す。
