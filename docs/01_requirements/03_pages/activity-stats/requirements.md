# 活動の統計の機能要件

## 目的

活動の量と内訳を期間ごとに確かめる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| activity-stats-F01 | 期間を選ぶ | 今日・週・月・年の集計を切り替えられる。 |
| activity-stats-F02 | 活動を比べる | 歩数・移動距離・訪問と活動の内訳を確認できる。 |
| activity-stats-F03 | 数値の出所を見る | 取得元・欠測を確認し対応する記録へ戻れる。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 集計期間・単位・取得元・欠測を示す。歩数とGPS距離を混算しない。0と未取得を区別する。
- 活動別の内訳から対象記録を確認する。期間変更でグラフと合計を同時に更新する。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
