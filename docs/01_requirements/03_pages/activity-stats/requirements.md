# 活動の統計の機能要件

## 目的

活動の量と内訳を期間ごとに確かめる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| activity-stats-F01 | 期間を選ぶ | 今日・週・月・年の集計を切り替えられる。 |
| activity-stats-F02 | 活動を比べる | 歩数・移動距離・訪問と活動の内訳を確認できる。 |
| activity-stats-F03 | 数値の出所を見る | 取得元・欠測を確認し対応する記録へ戻れる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 集計期間・単位・取得元・欠測を示す。歩数とGPS距離を混算しない。0と未取得を区別する。
- 活動別の内訳から対象記録を確認する。期間変更でグラフと合計を同時に更新する。
