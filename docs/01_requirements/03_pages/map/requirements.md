# 地図の機能要件

## 目的

場所を探し、保存して訪れる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| map-F01 | 場所を探す | 場所名や店名から候補を一覧と地図で確認できる。 |
| map-F02 | 場所を調べる | 写真・住所・説明・周辺候補を確認できる。 |
| map-F03 | 場所を保存する | 同じ候補を重複作成せず自分の保存対象へ追加できる。 |
| map-F04 | 経路を調べる | 選んだ場所を目的地として案内へ進める。 |
| map-F05 | 表示を変える | 2D・3Dや方角を変えても選択場所を維持できる。 |

## 保存と再表示

利用者が保存した場所。検索や2D/3D切替だけでは訪問や記録を作らない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 場所検索→候補詳細→場所保存または経路へ接続する。検索結果IDと候補IDを引き継ぎ、候補を既保存placeIdとして送らない。
- 2D/3D・レンズ・時間・現在地追従は独立して保持する。方角リセットや現在地操作は記録を作らない。
- 地図の帰属表示を残し、情報源の未確認事項を確定事実として表示しない。
