# プロフィールと表示の機能要件

## 目的

プロフィールと読みやすさを整える。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| profile-settings-F01 | 自己紹介を変える | 写真・表示名20文字・紹介200文字を変更できる。 |
| profile-settings-F02 | 表示を変える | 文字サイズと動きを減らす設定を選べる。 |
| profile-settings-F03 | 通知を選ぶ | 通知タイミングを指定できる。 |
| profile-settings-F04 | 保存する | 次回起動でも同じプロフィールと表示設定を使える。 |

## 保存と再表示

写真・名前・自己紹介・文字サイズ・動きを減らす・通知の設定。

## 成立条件と例外

- 表示名20文字・自己紹介200文字、写真、文字サイズ、動きを減らす、通知を保存する。大きな文字でもフォーム・地図・下部操作が重ならない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
