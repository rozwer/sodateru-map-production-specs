# Codexと探索の機能要件

## 目的

希望を話して街の候補を探す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| ai-explore-F01 | 文章で相談する | 希望と対象場所を送って候補や確認事項を受け取れる。 |
| ai-explore-F02 | 音声で入力する | 文字起こしを確認してから送れる。 |
| ai-explore-F03 | 候補を地図で見る | 相談で示された候補の位置と詳細を開ける。 |
| ai-explore-F04 | 処理を中止・再試行する | 入力を残して失敗や取消から再開できる。 |

## 保存と再表示

送信した相談と返された候補・選択の対応。会話履歴との接続はAPI不足一覧に従う。

## 成立条件と例外

- 相談文と現在地または選択場所を渡し、候補・不成立・確認事項を表示する。候補選択は本人の操作で確定する。
- 送信中・キャンセル・失敗・再試行を表示し、生成失敗でも入力を保持する。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
