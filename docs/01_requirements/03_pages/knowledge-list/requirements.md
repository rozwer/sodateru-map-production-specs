# 地域の知を探すの機能要件

## 目的

地域の体験や知恵を探す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| knowledge-list-F01 | 声を検索する | 検索文字と種類から投稿や人を探せる。 |
| knowledge-list-F02 | 条件を絞る | 地域・目的・期間・共有範囲を指定できる。 |
| knowledge-list-F03 | 投稿を読む | 本文・写真動画・作者・場所を詳細で読める。 |
| knowledge-list-F04 | 地図で見返す | 同じ検索条件の投稿を地図で開ける。 |

## 保存と再表示

利用者が明示的に付けた投稿のしおり。閲覧・検索だけでは投稿を作成しない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 検索文字・種類・地域・目的・期間・公開範囲で投稿を探し、件数・一覧・地図の条件を一致させる。写真動画と投稿者の体験を中心に表示する。
