# わたしの地図の機能要件

## 目的

自分の体験を場所とテーマで見返す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| personal-map-F01 | テーマで絞る | すべて・選択テーマの記録を地図に表示できる。 |
| personal-map-F02 | 場所の記憶を見る | 地点から訪れた記録と本人の言葉へ戻れる。 |
| personal-map-F03 | テーマを整える | 名前や所属する記録を編集できる。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- テーマIDで記録を絞り、場所・記録・用途の対応を地図と詳細で一致させる。テーマの件数や名称だけで同じテーマと判断しない。
- テーマ変更後も次元・カメラ・選択場所を保ち、訪れた記録とテーマ編集を開ける。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
