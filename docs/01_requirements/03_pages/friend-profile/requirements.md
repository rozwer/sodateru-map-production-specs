# 友達のプロフィールの機能要件

## 目的

相手の共有した体験を知る。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| friend-profile-F01 | プロフィールを見る | 相手の紹介と共有されたテーマ・最近の記録を読める。 |
| friend-profile-F02 | 友達関係を管理する | 申請を送り、受信した申請を承認して友達になれる。相互承認済みの関係だけを友達として表示する。 |
| friend-profile-F03 | 街の見方を試す | 相手の地図・共通点・ルートへ進める。 |
| friend-profile-F04 | 自分の記録を渡す | 共有する記録を選べる。 |

## 保存と再表示

友達申請と承認状態。プロフィール閲覧や申請送信だけで承認済みへしない。

## 成立条件と例外

- 相手が共有したプロフィール・テーマ・最近の記録を表示し、地図・比較・共有する記録の選択へつなぐ。友達は申請・承認に統一し、片方向フォローは設けない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。

## 確認済みの判断

- Q-FRIEND：申請・承認で友達になる機能に統一
