# 徒歩ナビゲーションの機能要件

## 目的

採用した経路に沿って移動する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| route-navigation-F01 | 進む方向を知る | 曲がる地点・方向・距離を見られる。 |
| route-navigation-F02 | 残りを確認する | 残距離・残時間・測位精度を確認できる。 |
| route-navigation-F03 | 全体を見返す | 案内を継続したまま地図や経路一覧を開ける。 |
| route-navigation-F04 | 案内を終える | 明示的な終了で案内を止められる。 |

## 保存と再表示

案内中/終了と現在の区間。画面を閉じるだけでは案内を終了しない。

## 成立条件と例外

- 曲がる方向と地点、残り距離・時間、測位精度を実経路から表示する。地図に戻ることと案内終了を区別し、画面を閉じただけで終了しない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
