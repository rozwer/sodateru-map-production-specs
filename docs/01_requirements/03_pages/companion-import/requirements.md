# 相棒をファイルから追加の機能要件

## 目的

作成済みの相棒を持ち込む。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| companion-import-F01 | ファイルを選ぶ | ZIPを読み込み形式と内容を確認できる。 |
| companion-import-F02 | 動きを見る | 検査に成功した相棒の姿と動作をプレビューできる。 |
| companion-import-F03 | 登録する | 一覧への登録と現在の相棒にする操作を分けられる。 |

## 保存と再表示

検査済み相棒の登録。今の相棒にするが選択されている場合だけ、現在選択も変更する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- v2ペット形式を読み、形式検査とプレビュー後に登録する。登録と現在の相棒への選択は別。画像指定のZIP上限50MBと元仕様6MiBは差分として解決する。壊れたファイルで現在の相棒を変更しない。
