# 友達の地図の機能要件

## 目的

友達の共有した街の見方を試す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| friends-map-F01 | 相手を探す | 名前で相手を検索して共有地図を切り替えられる。 |
| friends-map-F02 | 共有記録を見る | 相手の場所・用途・原文を確認できる。 |
| friends-map-F03 | 共通点を探す | 自分と相手の共有可能な体験を比較できる。 |
| friends-map-F04 | おすすめを歩く | 相手のルートを開いて自分の条件で経路を確認できる。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 友達の選択と共有された投稿・地図・比較対象を同期する。記録0件は共有情報がない状態とし、相手の活動がないとは断定しない。
- 相手の用途表示は自分の成長や用途を上書きしない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
