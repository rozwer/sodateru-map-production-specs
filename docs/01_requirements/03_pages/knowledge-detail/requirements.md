# 地域投稿の詳細の機能要件

## 目的

一つの地域投稿を詳しく読む。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| knowledge-detail-F01 | 体験を読む | 原文・写真動画・作者・日付・場所を確認できる。 |
| knowledge-detail-F02 | 動画を見る | 再生・停止・音量・シークを操作できる。 |
| knowledge-detail-F03 | 関連情報へ進む | 場所地図・作者の共有地図・出典を開ける。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 動画は利用者の再生操作で開始し、作者・日付・場所・原文を表示する。場所地図・作者地図へ同じ対象を渡す。共有取消後の本文をキャッシュから復活させない。
