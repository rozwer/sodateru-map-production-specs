# 訪問の確認の機能要件

## 目的

訪問候補を本人が確かめる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| visit-confirm-F01 | 場所を確かめる | 候補地点の地図と詳細を確認できる。 |
| visit-confirm-F02 | 訪問状態を選ぶ | 行った・行っていない・まだ分からないを選べる。 |
| visit-confirm-F03 | 確認を保存する | 状態を保存し訪問数と地図の成長に反映できる。 |

## 保存と再表示

対象訪問の確認済み・否定・確認待ちの状態。元の記録本文と観測位置は確認操作だけで削除しない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 行ったはconfirmed、行っていないはrejected、まだ分からないはcandidateとして保存する。候補の表示だけでconfirmedにしない。
- 否定・場所訂正後は軌跡の事実を捏造せず、訪問数と建物の成長を再集計する。記録本文は消さない。
