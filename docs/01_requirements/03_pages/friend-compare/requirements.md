# 友達との共通点の機能要件

## 目的

自分と友達の場所の使い方を比べる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| friend-compare-F01 | 意味を比べる | 双方の用途・理由・共通点と違いを並べて読める。 |
| friend-compare-F02 | 根拠を確かめる | 比較に使った共有記録を開ける。 |
| friend-compare-F03 | 地図を重ねる | 持ち主を区別して双方の場所を表示できる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 共有された記録の範囲で双方の用途・理由・共通点と違いを並べる。情報不足を共通点なしと断定しない。地図重ね合わせで持ち主を識別できる。
