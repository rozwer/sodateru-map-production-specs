# お願いを書くの機能要件

## 目的

欲しい機能を自分の言葉で残す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| feature-request-edit-F01 | お願いを書く | 表示名と200文字以内の本文を入力できる。 |
| feature-request-edit-F02 | 公開範囲を選ぶ | 本人だけの下書きか公開投稿を選べる。 |
| feature-request-edit-F03 | 保存する | 下書きと投稿を区別して一覧へ反映できる。 |

## 保存と再表示

表示名・本文・対象日時・公開範囲。既存投稿の編集は同じ投稿へ反映する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 本文200文字までと投稿時の表示名を確認する。下書きはprivate、投稿は本人が選んだ公開範囲で保存し、結果を一覧へ反映する。

## 詳細との対応

[画面定義・API・受入シナリオ](README.md)。

フォームは「人に頼む」と共用する。依頼相手は指定しない。投稿だけで自動開発や外部通知を開始しない。
