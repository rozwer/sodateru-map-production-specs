# 日記の機能要件

## 目的

一日の記憶を日記としてまとめる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| diary-F01 | 日を選ぶ | 対象日の日記を前後移動や日付選択で開ける。 |
| diary-F02 | 日記を書く | 本文と写真を追加・編集・削除できる。 |
| diary-F03 | 日記を残す | 本人が確認した内容を保存し別の日と混ざらず再表示できる。 |

## 保存と再表示

対象日と本文・写真。初回作成と同じ日記の編集を区別する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 対象日の日記を保存・編集・再表示する。AI下書きは本人が確認して保存し、自動公開しない。
- 写真の追加・削除、前後の日と日付選択を扱い、未保存本文を別の日記へ混ぜない。
