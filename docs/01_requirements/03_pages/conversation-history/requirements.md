# 相談履歴の機能要件

## 目的

過去の相談を読み直す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| conversation-history-F01 | 相談を探す | 日付と検索文字から保存した会話を見つけられる。 |
| conversation-history-F02 | 会話を開く | 同じ相談の発言と結果を再表示できる。 |
| conversation-history-F03 | 新しく始める | 既存会話を上書きせず別の相談を始められる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 相談を日付別に再表示し、同じconversationIdの発言を開く。新規相談は既存会話を上書きしない。
