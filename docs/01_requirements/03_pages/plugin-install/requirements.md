# 導入前の確認の機能要件

## 目的

追加される情報を確認して導入する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| plugin-install-F01 | 変更を確認する | 利用する地域・車種・追加レイヤーと未確認情報を確認できる。 |
| plugin-install-F02 | 導入する | 設定を保存して地図で使い始められる。 |
| plugin-install-F03 | 見送る | 取消では導入状態を変更しない。 |

## 保存と再表示

対象機能の導入状態と試用で選んだ設定。

## 成立条件と例外

- 使う情報と追加表示を確認し、導入で設定を保存する。成功後に地図で開け、再読込しても導入状態を保持する。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
