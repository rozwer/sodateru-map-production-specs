# 経路の候補の機能要件

## 目的

移動時間と条件から経路を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| route-results-F01 | 候補を比べる | 複数経路を地図と距離・時間で比べられる。 |
| route-results-F02 | 条件を確かめる | 成立・違反・未確認を区別して確認できる。 |
| route-results-F03 | 選び直す | 条件へ戻って再検索できる。 |
| route-results-F04 | 案内を始める | 採用可能な経路を保存して案内へ進める。 |

## 保存と再表示

本人が選んだ経路と案内状態。候補閲覧だけでは案内を開始しない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 候補線とカードを同期し、移動と滞在を含む合計時間、距離、成立・違反・不明を区別する。既知違反の経路を採用させず、不明を条件成立として採用させない。
