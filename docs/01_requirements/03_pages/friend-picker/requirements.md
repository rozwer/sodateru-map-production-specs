# 共有する友達の機能要件

## 目的

共有したい友達を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| friend-picker-F01 | 友達を探す | 名前から共有可能な友達を探せる。 |
| friend-picker-F02 | 相手を確認する | プロフィールを見て複数人を選べる。 |
| friend-picker-F03 | 選択を返す | 完了で共有確認へ選択一覧を返せる。 |

## 保存と再表示

この画面では共有設定を確定保存しない。選択した相手を共有画面の下書きへ返す。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 共有可能な友達を検索・複数選択し、完了で選択ID一覧を共有確認へ返す。この画面だけで共有を実行しない。

## 確認済みの判断

- Q-FRIEND：申請・承認で友達になる機能に統一
