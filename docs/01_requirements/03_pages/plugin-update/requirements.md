# 機能の更新の機能要件

## 目的

拡張機能の版を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| plugin-update-F01 | 変更点を読む | 現在版と次版の内容や地図表示を比較できる。 |
| plugin-update-F02 | 先に試す | 更新前にプレビューできる。 |
| plugin-update-F03 | 更新する | 保存済みスポットと設定を保って新しい版へ移れる。 |
| plugin-update-F04 | 元へ戻す・削除する | 前版への復帰と機能の削除を選び分けられる。 |

## 保存と再表示

採用した版と設定。更新・復帰・削除の結果を区別する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 現在版と更新版を比較・試用してから更新する。設定と保存済みスポットを保持し、前の版に戻す操作と削除を区別する。
