# 健康データの連携状態の機能要件

## 目的

健康データの連携状況と保存分を管理する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| health-status-F01 | 取得状況を見る | 取得元・最終取込・項目・日別の欠測を確認できる。 |
| health-status-F02 | 取り込みを止める | 新しい取得だけ停止し既存値を残せる。 |
| health-status-F03 | 保存分を消す | このアプリの健康データだけ削除しiPhoneの原本を保てる。 |

## 保存と再表示

新規取得の停止状態、またはこのアプリ内の健康データ削除結果。原本は削除しない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 停止は新規取込を止め既存保存値を維持する。削除はこのアプリの保存分だけで、iPhoneの原本を消さない。未取得と0を区別する。
