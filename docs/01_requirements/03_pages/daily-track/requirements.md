# 今日の軌跡の機能要件

## 目的

一日の移動と体験を時系列で振り返る。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| daily-track-F01 | 日付を選ぶ | 前後の日やカレンダーから対象日を開ける。 |
| daily-track-F02 | 軌跡を読む | 訪問・移動・欠測を地図と時系列で確認できる。 |
| daily-track-F03 | 記録を開く | 写真・本文・場所を展開して見られる。 |
| daily-track-F04 | 追記や振り返りへ進む | 選んだ記録を編集したり質問へ渡せる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 対象日とタイムゾーンを共通にして軌跡・訪問・記録を表示する。候補・確認済み・否定済み・欠測を区別し、欠測区間を線で補わない。
- 日付変更・カレンダー・記録展開を同じ面で扱い、編集や振り返りから日付・展開行・スクロール位置へ戻る。
