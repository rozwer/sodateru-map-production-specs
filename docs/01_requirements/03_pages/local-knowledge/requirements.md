# 地域の知の機能要件

## 目的

地図上で地域の声を読む。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| local-knowledge-F01 | 場所を選ぶ | 選択地点と対応する共有情報を表示できる。 |
| local-knowledge-F02 | その場所の声を見る | 同じ場所に寄せられた体験の一覧へ進める。 |
| local-knowledge-F03 | 現在地から探す | 現在地取得に成功した場合に周辺へ移動できる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 選択地点の声を同じplaceIdで読む。投稿者・元の言葉・投稿日と、店舗の現在の提供情報を区別する。
