# 地図に配置の機能要件

## 目的

オブジェクトを置く位置を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| object-place-F01 | 場所を動かす | 地図を動かして中央マーカーで配置候補を選べる。 |
| object-place-F02 | 周囲を見る | 現在地移動・拡大縮小・レイヤー切替で位置を確かめられる。 |
| object-place-F03 | 位置を返す | 確定で編集下書きへ座標を返し、取消で以前の位置を保てる。 |

## 保存と再表示

確定した位置を編集下書きへ返す。オブジェクトの保存は編集画面の保存操作で行う。

## 成立条件と例外

- 地図中央のマーカーを配置点として選び、地図移動・ズーム・現在地で候補を変える。確定で編集画面へ座標を返し、取消で元の配置を保つ。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。

## 確認済みの判断

- Q-OBJECT：本人が追加した飾り・目印を対象とする。体験で育つ建物は記録と用途の訂正で変える。
