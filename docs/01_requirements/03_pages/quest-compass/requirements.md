# 探索コンパスの機能要件

## 目的

探索対象の方角と直線距離を知る。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| quest-compass-F01 | 方角を見る | 現在地から対象への方向と直線距離を見られる。 |
| quest-compass-F02 | 測位を確かめる | 更新時点と取得不能を識別できる。 |
| quest-compass-F03 | 移動を切り替える | 道路経路を開くかコンパスを終了できる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 方向と直線距離を測位時点と共に表示する。道路沿いの案内と区別し、測位停止時に距離を更新したように見せない。
