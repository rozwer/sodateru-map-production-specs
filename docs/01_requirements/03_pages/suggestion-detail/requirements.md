# 提案候補の詳細の機能要件

## 目的

候補の理由を確かめて行き先を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| suggestion-detail-F01 | 提案理由を読む | 自分の希望と候補が結び付いた根拠を確認できる。 |
| suggestion-detail-F02 | 現在の情報を確かめる | 公式情報と未確認事項を区別して読める。 |
| suggestion-detail-F03 | 行き先にする | 選択を保存して同じ場所を地図で開ける。 |
| suggestion-detail-F04 | あとに回す | 保留やメモを残して候補一覧へ戻れる。 |

## 保存と再表示

候補の選択・保留・しおり・本人のメモを別々に保持する。詳細を見ただけでは選択や訪問を確定しない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 確認済みの情報と不明な情報、元の希望と提案理由を分ける。これにするで選択を保存して地図へ渡し、あとでは保留として保持する。
