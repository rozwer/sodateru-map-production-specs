# 提案とまとめの条件の機能要件

## 目的

提案とまとめの使い方を決める。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| suggestion-settings-F01 | 提案のタイミングを選ぶ | 自分で開いたときか継続受取かを選べる。 |
| suggestion-settings-F02 | 集計期間を決める | まとめに使う記録の範囲を選べる。 |
| suggestion-settings-F03 | 停止対象を管理する | 場所と活動ごとの提案停止を確認して解除できる。 |

## 保存と再表示

提案タイミング・まとめの対象期間・場所と活動ごとの停止/解除。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 感想の低評価と、特定の場所＋活動に対する明示的な停止を別扱いにする。停止は本人が解除するまで維持し、全体の提案タイミングを守る。
