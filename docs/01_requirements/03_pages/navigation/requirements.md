# 共通メニュー・モード切替の機能要件

## 目的

目的の機能へ移動する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| navigation-F01 | 機能を選ぶ | 地図・自分・みんな・拡張機能・設定へ移動できる。 |
| navigation-F02 | モードを変える | 自分側とみんな側の表示を選べる。 |
| navigation-F03 | 元の作業へ戻る | 選択場所・日付・編集中内容を保ってメニューを閉じられる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 添付の最新メニュー・下部ナビを正本にする。旧リポの4タブ順は移植しない。メニューを閉じると元画面とフォーカスへ戻す。
- 地図範囲・選択場所・日付・編集中入力を遷移で引き継ぎ、記録中・案内中の状態は画面を離れただけで停止しない。
