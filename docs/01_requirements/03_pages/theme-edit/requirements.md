# テーマを編集の機能要件

## 目的

テーマの内容と見た目を整える。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| theme-edit-F01 | 名前と説明を付ける | 名前20文字・説明100文字まで書ける。 |
| theme-edit-F02 | 見た目を選ぶ | 7色と代表写真を選べる。 |
| theme-edit-F03 | 体験をまとめる | 複数の記録をテーマに含められる。 |
| theme-edit-F04 | 変更を残す | 保存後に一覧と地図へ反映し取消で元の値を保てる。 |

## 保存と再表示

テーマ名・説明・色・代表写真・所属記録。同じ記録を別テーマにも含められる。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 名前20文字・説明100文字、7色、写真、複数記録の選択を編集し、保存後に一覧と地図へ反映する。取消で保存済み値を変えない。
