# 振り返りの質問の機能要件

## 目的

一問ずつ体験の理由を振り返る。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| reflection-question-F01 | 対象を確認する | 質問の元となった記録を開ける。 |
| reflection-question-F02 | 答える | 自由文で回答を保存できる。 |
| reflection-question-F03 | 後回しにする | あとでとスキップを別々に記録できる。 |

## 保存と再表示

対象質問・回答原文・回答済み/あとで/スキップの状態。回答の保存と分析完了を区別する。

## 成立条件と例外

- 質問は一度に1問。回答・あとで・スキップを区別し、既に話した理由を新しい根拠なしに繰り返さない。
- 原文保存とAIによる整理の成功を別に示し、AI失敗でも回答を失わない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
