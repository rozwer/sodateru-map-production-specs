# 共有範囲の確認の機能要件

## 目的

見せる内容と相手を決めて共有する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| sharing-F01 | 内容を確認する | 共有される写真と本文をプレビューできる。 |
| sharing-F02 | 範囲を選ぶ | 自分だけ・選んだ友達・公開を選べる。 |
| sharing-F03 | 相手を選ぶ | 共有する友達を複数指定できる。 |
| sharing-F04 | 共有を確定する | 保存操作で初めて選んだ範囲に反映できる。 |

## 保存と再表示

対象記録の公開範囲と選択した友達。選択画面の完了だけではなく、この画面の共有確定で反映する。

## 成立条件と例外

- 共有する写真と本文を事前表示し、自分だけ・選んだ友達・公開を選べる。診断や非公開履歴を同時公開しない。
- 選んだ友達にはsharedWithの人物IDを使い、選択0人で意図せず公開へ変更しない。保存前の選択変更だけでは共有しない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
