# 体験で地図が育ったの機能要件

## 目的

体験が地図へ反映された結果を見る。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| growth-result-F01 | 成長を見る | 確認済みの訪問と用途による建物の変化を見られる。 |
| growth-result-F02 | 根拠を見返す | 成長に結び付いた元の体験を開ける。 |
| growth-result-F03 | 次へ進む | 次の候補を探すか地図へ戻れる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 本人が確認した訪問と用途に基づき建物の成長を表示する。元記録へ戻れ、削除・用途訂正後は現在の有効情報で再集計する。
