# 相棒の制作の機能要件

## 目的

希望に合う相棒を制作する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| companion-create-F01 | 希望を書く | 名前20文字・外見200文字と任意の参考画像を入力できる。 |
| companion-create-F02 | 作り方を選ぶ | 接続済みの生成先を使うか下書きや制作指示を持ち出せる。 |
| companion-create-F03 | 候補を確認する | 生成進捗と結果の動きを見て採用できる。 |
| companion-create-F04 | 後で再開する | 未接続や失敗でも入力を残せる。 |

## 保存と再表示

制作下書き・生成処理の状態・生成候補・採用結果。採用と現在の相棒への設定は分ける。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 接続先を確認し、入力→生成→動作確認→採用→選択へ進む。未接続時は生成を無効にし、下書き保存と指示の持出しを使える。生成結果を自動採用しない。
