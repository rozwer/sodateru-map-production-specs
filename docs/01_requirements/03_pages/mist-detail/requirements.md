# もやの探索候補の機能要件

## 目的

未形成の探索候補を確かめて向かう。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| mist-detail-F01 | 候補を調べる | 写真・入口・理由・出典を確認できる。 |
| mist-detail-F02 | 後で見返す | 候補を保存できる。 |
| mist-detail-F03 | 向かい方を選ぶ | 道路経路または直線方向のコンパスを開ける。 |

## 保存と再表示

候補のしおり。候補の保存・閲覧・近接だけでは訪問と成長を確定しない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- もやは未形成の候補として表示する。写真・入口・理由・情報源を確認して経路またはコンパスへ進む。保存や接近だけで成長させない。
