# 拡張機能を探すの機能要件

## 目的

使いたい拡張機能を探す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| plugin-store-F01 | 機能を探す | 名前・実現したいこと・分類から候補を絞れる。 |
| plugin-store-F02 | 詳細を確認する | 内容と追加表示を見て試用へ進める。 |
| plugin-store-F03 | 導入済みを管理する | 使用中の機能へすぐ戻れる。 |
| plugin-store-F04 | 開発へ参加する | 要望を書くか開発ガイドを開ける。 |
