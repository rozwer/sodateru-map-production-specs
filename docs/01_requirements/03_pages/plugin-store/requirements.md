# 拡張機能を探すの機能要件

## 目的

使いたい拡張機能を探す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| plugin-store-F01 | 機能を探す | 名前・実現したいこと・分類から候補を絞れる。 |
| plugin-store-F02 | 詳細を確認する | 内容と追加表示を見て試用へ進める。 |
| plugin-store-F03 | 導入済みを管理する | 使用中の機能へすぐ戻れる。 |
| plugin-store-F04 | 開発へ参加する | 要望を書くか開発ガイドを開ける。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 名前・実現したいこと・分類から拡張機能を探し、詳細と導入済み管理へ進む。作る人はGitHubガイド、使う人はアプリ内の試用・導入へ進む。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
