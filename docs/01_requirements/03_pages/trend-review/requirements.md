# 傾向の確認・訂正の機能要件

## 目的

傾向への本人の判断を残す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| trend-review-F01 | 判断を選ぶ | 合っている・違う・まだ分からないを選べる。 |
| trend-review-F02 | 理由を添える | 200文字以内の任意の説明を付けられる。 |
| trend-review-F03 | 判断を保存する | 次回表示にも判断を反映し、訪問事実を勝手に変更しない。 |

## 保存と再表示

対象傾向への合う・違う・不明の判断と任意理由。元の訪問事実は変えない。

## 成立条件と例外

- agree/disagree/unsureと任意理由を保存する。否定した解釈を同じ根拠だけで復活させず、訪問事実や確認済み用途は維持する。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
