# 体験を編集の機能要件

## 目的

保存した体験を修正する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| record-edit-F01 | 本人の言葉を直す | 本文・感想・気分・滞在時刻を変更できる。 |
| record-edit-F02 | 用途を直す | 読書・休憩など実際の用途を複数選べる。 |
| record-edit-F03 | 媒体を整える | 写真の追加・削除と並び順を変更できる。 |
| record-edit-F04 | 変更を保存する | 同じ記録を更新して一覧・地図の関連表示へ反映できる。 |

## 保存と再表示

同じ記録の本文・用途・感想・時刻・媒体・しおり。媒体の変更と本文保存の成否を区別する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 同じrecordIdを編集し、用途は複数選択、本人の言葉・感想・時刻・媒体・しおりを個別に保持する。用途変更は成長へ反映し、感想や理由だけの変更で訪問事実を変えない。
- 媒体を外す操作の対象は選んだmediaIdのみ。保存後は一覧・詳細・再読込で更新結果を確認する。
