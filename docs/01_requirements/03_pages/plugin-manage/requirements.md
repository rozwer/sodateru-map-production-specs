# 導入済みの機能の機能要件

## 目的

導入した機能を使い分ける。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| plugin-manage-F01 | 有効化を切り替える | 各機能をON/OFFできる。 |
| plugin-manage-F02 | 使う条件を整える | 地域などの条件やアイコンを変更できる。 |
| plugin-manage-F03 | 地図で使う | 設定した機能を同じ地図で開ける。 |
| plugin-manage-F04 | 更新や管理へ進む | 更新・相棒・別の機能探しへ進める。 |

## 保存と再表示

対象機能の有効状態・条件・アイコン。無効化はデータ削除ではない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 導入済み機能の有効化・無効化・条件変更・更新を見つけられるようにする。無効化しても記録や保存スポットを削除しない。
