# 相棒の管理の機能要件

## 目的

地図で一緒に表示する相棒を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| companion-settings-F01 | 相棒を選ぶ | 登録済みの相棒から現在の相棒を選べる。 |
| companion-settings-F02 | 表示を整える | 表示ON/OFF・大きさ・動きを減らす設定を選べる。 |
| companion-settings-F03 | 追加へ進む | ファイルを持ち込むか新しい相棒を制作できる。 |
| companion-settings-F04 | 選択を残す | 保存後も同じ相棒と表示設定を使える。 |

## 保存と再表示

選択した相棒・表示・サイズ・動きを減らす設定。

## 成立条件と例外

- 登録済み相棒の選択・表示ON/OFF・サイズ・動きを減らすを保存する。相棒を非表示にしてもAI入口を残し、主要操作を塞がない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
