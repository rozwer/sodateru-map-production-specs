# 提案候補一覧の機能要件

## 目的

今日の条件に合う候補を比べる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| suggestions-F01 | 候補を比べる | 理由・移動時間・滞在時間・合計・評価状態を確認できる。 |
| suggestions-F02 | 条件を変える | 希望や制約を直して候補を探し直せる。 |
| suggestions-F03 | 詳しく見る | 選んだ候補の確認済み情報と不明点へ進める。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 現在希望を過去の習慣より優先し、候補の理由・移動時間・滞在時間・合計を表示する。未評価と低評価を区別する。
- 0件は理由と条件変更入口を示す。候補表示・詳細閲覧・選択・訪問は別の状態として保存する。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
