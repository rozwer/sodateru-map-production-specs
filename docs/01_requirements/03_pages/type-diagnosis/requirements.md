# タイプ診断の機能要件

## 目的

最近の行動傾向を根拠付きで知る。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| type-diagnosis-F01 | 期間を切り替える | 今日・今週・今月・これまでの結果を見られる。 |
| type-diagnosis-F02 | 傾向を見る | 対象期間の仮の呼び名・グラフ・変化を確認できる。 |
| type-diagnosis-F03 | 根拠を確認する | 元体験と反例・情報不足へ戻れる。 |
| type-diagnosis-F04 | 本人の判断を残す | 合う・違う・不明を伝えて今の希望から探索へ進める。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 今日・今週・今月・これまでの対象期間を表示し、期間内の記録に基づく仮の呼び名とグラフを出す。固定的人格・偉人比較・根拠なしの点数を出さない。
- 根拠・別の説明・欠測・本人の確認状態へ進める。2体験からの仮説生成を検証済みの傾向と呼ばない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
