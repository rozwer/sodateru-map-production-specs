# メモを編集の機能要件

## 目的

気付きや次の希望をメモに残す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| memo-edit-F01 | 内容を編集する | 名前20文字・本文200文字とキーワードを書ける。 |
| memo-edit-F02 | 由来を残す | 体験や候補とのつながりを記録できる。 |
| memo-edit-F03 | 提案への利用を選ぶ | メモを今後の提案に使うか切り替えられる。 |
| memo-edit-F04 | 整理する | 保存・取消・削除を選べる。 |

## 保存と再表示

名前・本文・由来・キーワード・提案への利用設定。独立本文は由来と別の削除対象。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 名前20文字・本文200文字・由来・キーワード・提案利用ON/OFFを保存する。由来の削除と独立したメモ本文の削除は分ける。
