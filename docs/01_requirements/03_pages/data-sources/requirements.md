# データの取得元の機能要件

## 目的

数値や訪問情報がどこから来たか確認する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| data-sources-F01 | 取得元を確認する | 歩数と訪問の取得方法・時点を読める。 |
| data-sources-F02 | 連携を管理する | 未連携や取得失敗から健康連携の設定へ進める。 |
| data-sources-F03 | 訪問履歴を読む | 集計に使われた訪問を日付で見返せる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 歩数の取得元・訪問の取得元と最終取得時点を示す。権限なし・未連携・取得失敗を区別し設定へつなぐ。
