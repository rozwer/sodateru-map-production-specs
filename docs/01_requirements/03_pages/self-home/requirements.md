# 自分を知るの機能要件

## 目的

記録から振り返りを始める。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| self-home-F01 | 今日の軌跡を見る | 今日の訪問・移動・体験を日付付きで開ける。 |
| self-home-F02 | 自分の傾向を知る | 期間内の傾向と根拠を開ける。 |
| self-home-F03 | 自分の地図を見る | 記録やテーマから場所を見返せる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 画像の今日の軌跡・タイプ診断・わたしの地図の3入口を実際の画面へ接続する。旧リポの静的入口だけの制限は引き継がない。
- 位置情報未許可・記録0件でも入口を表示し、最近の記録を架空データで埋めない。
