# 自分を知るの機能要件

## 目的

記録から振り返りを始める。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| self-home-F01 | 今日の軌跡を見る | 今日の訪問・移動・体験を日付付きで開ける。 |
| self-home-F02 | 自分の傾向を知る | 期間内の傾向と根拠を開ける。 |
| self-home-F03 | 自分の地図を見る | 記録やテーマから場所を見返せる。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 画像の今日の軌跡・タイプ診断・わたしの地図の3入口を実際の画面へ接続する。旧リポの静的入口だけの制限は引き継がない。
- 位置情報未許可・記録0件でも入口を表示し、最近の記録を架空データで埋めない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
