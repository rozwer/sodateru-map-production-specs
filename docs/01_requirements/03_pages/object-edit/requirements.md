# 地図オブジェクトを編集の機能要件

## 目的

地図上の表現を自分で整える。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| object-edit-F01 | 内容を変える | 名前20文字・メモ200文字を編集できる。 |
| object-edit-F02 | 見た目を変える | 6色と小中大の表示サイズを選べる。 |
| object-edit-F03 | 配置を変える | 場所を選び直してプレビューできる。 |
| object-edit-F04 | 確定する | 自分で追加した飾り・目印の保存・取消・削除を選べる。体験で育つ建物は記録と用途の訂正で変更する。 |

## 保存と再表示

本人が追加した飾り・目印の名前・メモ・色・表示サイズ・配置位置。実建物の形状・高さと体験由来の成長は変更しない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 名前20文字・メモ200文字・6色・小中大の表示サイズと配置場所を編集する。サイズは地図上の表現であり実建物の高さを書き換えない。

## 確認済みの判断

- Q-OBJECT：本人が追加した飾り・目印を対象とする。体験で育つ建物は記録と用途の訂正で変える。
