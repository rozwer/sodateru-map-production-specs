# 二つの体験を比較の機能要件

## 目的

二つの体験の共通点と違いを言葉にする。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| experience-compare-F01 | 体験を並べる | 選んだ2件の場所・日時・言葉を見比べられる。 |
| experience-compare-F02 | 比較を書く | 共通点と違いをそれぞれ100文字以内で書ける。 |
| experience-compare-F03 | 比較を残す | 対象2件と比較文を保存し元記録と共に再表示できる。 |

## 保存と再表示

対象の2記録と共通点・違いの本文。元記録を編集しても比較対象が別の記録へ入れ替わらない。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 異なる2件の記録をIDで選び、共通点と違いを別々に100文字まで入力して保存・再表示する。共通の用途を場所全体の同一性や同じ好みと断定しない。
