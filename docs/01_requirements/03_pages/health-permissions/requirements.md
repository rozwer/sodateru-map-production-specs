# 健康データの項目と期間の機能要件

## 目的

使う健康情報の範囲を決める。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| health-permissions-F01 | 項目を選ぶ | 歩数・歩行距離・活動時間を選択できる。 |
| health-permissions-F02 | 期間を選ぶ | 取り込む対象期間を指定できる。 |
| health-permissions-F03 | 用途を選ぶ | アプリ内保存とAI利用を別々に選択できる。 |
| health-permissions-F04 | 開始を決める | 許可して続けるか何も取り込まず戻れる。 |

## 保存と再表示

選択した項目・期間・保存/AI利用の同意。AI利用OFFでも他の同意範囲内で取り込みを利用できる。

## 成立条件と例外

- 項目と期間、保存、AI利用を別に選択する。健康値を場所の訪問や性格へ推定変換しない。AI利用は同意した範囲だけにする。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
