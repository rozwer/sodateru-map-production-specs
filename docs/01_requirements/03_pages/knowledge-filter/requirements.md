# 地域の知の絞り込みの機能要件

## 目的

地域の声を探す範囲と条件を決める。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| knowledge-filter-F01 | 範囲を選ぶ | 検索地域と半径または地図範囲を選べる。 |
| knowledge-filter-F02 | 内容を絞る | 目的・期間・共有範囲を選べる。 |
| knowledge-filter-F03 | 条件を適用する | 適用時に一覧へ反映し取消では以前の条件を維持できる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 編集中条件は適用まで一覧へ反映しない。閉じるで適用済み条件へ戻し、クリア後の適用で条件を解除する。距離の中心と地図範囲を区別する。
