# 地域の知の絞り込みの機能要件

## 目的

地域の声を探す範囲と条件を決める。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| knowledge-filter-F01 | 範囲を選ぶ | 検索地域と半径または地図範囲を選べる。 |
| knowledge-filter-F02 | 内容を絞る | 目的・期間・共有範囲を選べる。 |
| knowledge-filter-F03 | 条件を適用する | 適用時に一覧へ反映し取消では以前の条件を維持できる。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 編集中条件は適用まで一覧へ反映しない。閉じるで適用済み条件へ戻し、クリア後の適用で条件を解除する。距離の中心と地図範囲を区別する。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
