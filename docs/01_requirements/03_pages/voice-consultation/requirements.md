# 音声で相談の機能要件

## 目的

声を確認可能な相談文にする。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| voice-consultation-F01 | 録音する | マイク許可後に録音時間と状態を確認できる。 |
| voice-consultation-F02 | 文章に直す | 停止後の文字起こしを編集・消去できる。 |
| voice-consultation-F03 | 送る内容を決める | 本人が確認した文章だけを相談へ送れる。 |

## 保存と再表示

送信時に確認した文字起こしを相談文として保存する。録音原本の永続保存は要求しない。

## 成立条件と例外

- 録音開始前に端末のマイク許可を得る。停止後に文字起こしを編集・消去でき、送る操作で確認した本文だけを相談へ渡す。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
