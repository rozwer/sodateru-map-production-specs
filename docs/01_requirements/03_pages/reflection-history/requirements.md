# 振り返りの記録の機能要件

## 目的

過去の回答と未回答の質問を見返す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| reflection-history-F01 | 状態で絞る | すべて・回答済み・あとで・スキップを切り替えられる。 |
| reflection-history-F02 | 回答を読む | 質問と回答を展開して元記録を確認できる。 |
| reflection-history-F03 | 解釈に反映する | 保存した回答を根拠として解釈を更新できる。 |

## 保存と再表示

保存済み回答は読取対象。解釈更新を確定したときだけ、対象回答を根拠にした解釈を更新する。

## 成立条件と例外

- 回答済み・あとで・スキップを保持し、フィルターと展開を変えても状態が戻らない。元記録と回答から解釈の更新へ進む。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
