# 傾向の根拠の機能要件

## 目的

傾向がどの体験から生まれたか確かめる。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| trend-evidence-F01 | 根拠を読む | 本人の言葉と観測と推定を区別して読める。 |
| trend-evidence-F02 | 別の説明を確かめる | 反例や記録のない日を確認できる。 |
| trend-evidence-F03 | 元記録へ戻る | 対象体験を開き、必要なら解釈訂正へ進める。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 根拠となる複数体験・本人の言葉・観測・AI推定・反例・未知を別表示し、元記録へ戻れる。
