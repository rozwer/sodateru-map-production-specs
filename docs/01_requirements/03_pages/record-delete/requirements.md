# 記録を削除の機能要件

## 目的

影響を確かめて記録を削除する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| record-delete-F01 | 消える範囲を確認する | 記録・媒体・関連解釈・共有と残る独立情報を確認できる。 |
| record-delete-F02 | 控えを残す | 削除前に対象データを書き出せる。 |
| record-delete-F03 | 削除を確定する | 削除後は一覧・地図・共有から対象が消え、取消では維持できる。 |

## 保存と再表示

削除結果。対象の本文・媒体・関連表示の扱いと、残る独立記録・メモを区別する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 対象記録・媒体・派生情報・共有の削除範囲と、残る独立記録・メモ・設定を事前表示する。
- 削除完了後は一覧・詳細・地図・共有から消えたことを確認する。処理中・失敗を完了表示しない。
