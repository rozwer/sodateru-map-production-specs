# 拡張機能を試すの機能要件

## 目的

導入前に地図の変化を試す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| plugin-trial-F01 | 条件を選ぶ | 地域・車種・高速道路利用を指定できる。 |
| plugin-trial-F02 | 模擬表示を見る | 模擬データと分かる状態で導入前後を同じ地図上で見られる。 |
| plugin-trial-F03 | 導入へ進む | 試した条件を保って確認画面へ進める。 |

## 保存と再表示

導入設定はまだ保存しない。試用条件を導入確認の下書きとして引き継ぐ。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 地域・車種・高速道路条件を使った模擬プレビューを表示する。実データと混ぜず、未確認道路を走行可能としない。導入前後の変化を同じ地図範囲で自動表示する。
