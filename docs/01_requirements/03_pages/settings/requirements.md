# 設定の機能要件

## 目的

アプリの利用方法とデータを管理する。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| settings-F01 | 設定を開く | プロフィール・位置・写真マイク・AI・提案・健康・データ・表示を選べる。 |
| settings-F02 | 現在値を知る | 各機能の有効状態と連携状態を概要で確認できる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 設定の各入口から現在値を確認・変更できる。未連携・権限なし・利用OFFを同じ状態とせず概要を更新する。
