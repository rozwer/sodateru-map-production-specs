# 体験を残すの機能要件

## 目的

体験を写真・動画・言葉で残す。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| record-create-F01 | 体験を入力する | 本文だけ・媒体だけでも下書きを作れる。 |
| record-create-F02 | 場所と日時を付ける | 地図・検索・訪問履歴から場所を選び、不明なら未指定で残せる。 |
| record-create-F03 | 保存前に確認する | 媒体・本文・訪問確認・公開範囲を見直せる。 |
| record-create-F04 | 記録を保存する | 確定した内容を保存し一覧と詳細から再表示できる。 |

## 保存と再表示

本人が確定した本文・媒体と並び順・場所・日時精度・公開範囲。本人確認した訪問は記録本文と別に保持する。

## 成立条件と例外

- 写真・動画だけ、本文だけ、日時や場所が不明な体験も保存できる。撮影時刻や現在地を無断で体験日時・訪問場所に確定しない。
- 確認画面で媒体・本文・場所・日時・公開範囲を見直す。行きましたの本人確認と記録保存を区別し、閲覧や場所選択だけで訪問を作らない。
- 媒体の順番と失敗した項目を保持し、本文保存済み・媒体処理中・一部失敗を区別する。既定は自分だけ。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
