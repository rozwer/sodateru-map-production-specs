# 友達のおすすめルートの機能要件

## 目的

友達のルートを確かめて自分でも使う。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| shared-route-F01 | 行程を読む | 作者・目的・立ち寄り順・各地点の説明を確認できる。 |
| shared-route-F02 | 時間を確認する | 移動と滞在を含む共有行程を読める。 |
| shared-route-F03 | 自分用に調べる | 自分の移動条件で再検索し元ルートとの違いを確認できる。 |

## 保存と再表示

[閲覧のみの画面の条件](../README.md#閲覧のみの画面)を適用する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- 作成者・テーマ・立ち寄り順・各地点の説明と時間を表示する。元ルートと自分の条件による変更案を区別する。
