# 友達のおすすめルートの機能要件

## 目的

友達のルートを確かめて自分でも使う。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| shared-route-F01 | 行程を読む | 作者・目的・立ち寄り順・各地点の説明を確認できる。 |
| shared-route-F02 | 時間を確認する | 移動と滞在を含む共有行程を読める。 |
| shared-route-F03 | 自分用に調べる | 自分の移動条件で再検索し元ルートとの違いを確認できる。 |

## 保存と再表示

このページでの閲覧・検索・選択だけでは、保存済みの体験や相手の情報を変更しない。選択した対象・日付・条件を遷移先へ渡し、戻ったときに元の文脈を再表示する。

## 成立条件と例外

- 作成者・テーマ・立ち寄り順・各地点の説明と時間を表示する。元ルートと自分の条件による変更案を区別する。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
