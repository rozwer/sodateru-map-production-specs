# 今日はどう過ごしたい？の機能要件

## 目的

今の状態と今日の希望を次の行き先へつなぐ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| self-checkin-F01 | 希望を入力する | 状態・したいこと・使える時間を任意で書ける。 |
| self-checkin-F02 | 条件を選ぶ | 移動手段・同行者・歩く負担を指定できる。 |
| self-checkin-F03 | 候補を探す | 今の入力を優先した候補一覧へ進める。 |
| self-checkin-F04 | 回答だけ残す | 候補を作らず回答を保存できる。 |
| self-checkin-F05 | 未回答で使う | 入力せず地図へ進める。 |

## 保存と再表示

対象日・今の状態・今日の希望・条件・有効期限。回答だけ保存では候補の選択や訪問を作らない。

## 成立条件と例外

- 今の状態と今日の希望を任意入力する。回答だけ保存・未回答で地図へを残し、過去の希望を当日の希望として自動適用しない。
- 15/30/60/120分以上、移動手段、同行者、負担の条件を保持する。120分以上を上限120分へ変換しない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
