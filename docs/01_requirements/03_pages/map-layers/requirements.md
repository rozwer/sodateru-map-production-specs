# 地図の表示設定の機能要件

## 目的

地図に重ねる情報を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| map-layers-F01 | 表示を切り替える | テーマ・探索候補・友達・バイクの情報を個別に表示できる。 |
| map-layers-F02 | 地図で確認する | 表示変更を地図ですぐ確認できる。 |
| map-layers-F03 | 表示を戻す | 非表示にしても元データを消さず再表示できる。 |

## 保存と再表示

各レイヤーの表示設定。元の記録・友達関係・導入済み機能は非表示にしても保持する。

## 成立条件と例外

[共通の成立条件](../README.md#共通の成立条件)を適用する。

- テーマ・候補・友達・バイクマップの表示を個別に切り替える。非表示操作で記録やプラグインを削除せず、再表示で同じ対象を戻す。
