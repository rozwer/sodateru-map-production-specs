# 変更が重なる場合の機能要件

## 目的

表示の競合を見て併用方法を選ぶ。

## このページでできること

| ID | 機能 | 操作後にできること・確認できる結果 |
|---|---|---|
| plugin-conflict-F01 | 影響を確認する | 同じ対象の色分けなど競合箇所を比較できる。 |
| plugin-conflict-F02 | 併用を選ぶ | 違いを確認した上で両方使える。 |
| plugin-conflict-F03 | 片方を止める | 選んだ機能だけ無効化できる。 |

## 保存と再表示

利用者が選んだ併用/無効化の結果。選んでいない機能は削除しない。

## 成立条件と例外

- 競合する対象と双方の表示を具体的に示し、併用・片方の無効化・戻るを選べる。勝手に片方を削除しない。
- 対象データがない場合は、その対象の0件状態と次にできる操作を表示する。取得できない状態を0件と同一視しない。
- 保存や取得に失敗した場合は入力と対象を保持し、処理結果が分かる状態で再試行できる。
- [共通要件](../common.json)の画面サイズ・文字拡大・メニュー開閉時の操作可能性を満たす。
