# AIとのやり取り

用途別の材料を組み立ててAIへ渡し、結果を依頼元の画面へ返す。

## 使途と結果の反映先

### 地図で行き先を相談する

地図の相談欄で「近くのカフェを探して」「2番目まで歩きたい」と頼む。
本人の言葉、出発点、直前の候補をAIへ渡し、必要な検索を選ばせる。
検索結果を読んだ返事は会話へ、候補の位置と経路は地図へ返す。

後から読む会話は [会話](../../01_DB/04_conversations.json)と[発言](../../01_DB/05_messages.json)、保存する道順は [保存ルート](../../01_DB/06_saved_routes.json)へつなぐ。
街歩き相談の一時会話は[検索ループ](04_map-dialogue.md)、保存して読み直す相談は[AIの保存](03_storage-ui.md)を使う。

### 体験の文章を整理する

体験の記録画面で、保存した文章の用途や理由を整理するときに使う。
たとえば「本を読みに来たが、友人と話して気分転換になった」という原文と、本人の追加回答を渡す。
用途・理由の案を同じ記録の確認欄へ返し、本人が訂正して採用する。

採用した内容は [記録](../../01_DB/02_records.json)へ反映し、原文も保持する。
訪問の確認は [訪問](../../01_DB/15_visits.json)の操作で行う。

### 日記の下書きを作る

自分を知る画面で日付を選び、その日の記録から日記をまとめるときに使う。
対象日と使用する記録を渡し、作成した文章を日記の編集欄へ返す。
本人が読み直して保存した文章を [記録](../../01_DB/02_records.json)の日記として残す。

生成中も編集欄の文章を保持し、下書きの採用後に本人が保存する。

### 傾向を説明し、テーマに名前を付ける

傾向画面では、選んだ期間の記録と計算済みの集計から説明文を作る。
テーマ編集では、本人が選んだ複数の記録から名前や説明の案を作る。
結果は傾向の説明欄やテーマの編集欄へ返す。

日数・回数は分析機能が計算し、AIは説明・命名を担当する。
保存する説明と根拠、本人の判断は [分析・比較結果](../../01_DB/16_insights.json)、採用したテーマ名と所属記録は [テーマ](../../01_DB/13_themes.json)へつなぐ。

### 体験を比較する

自分の二つの体験や、自分と他の人の体験を比較するときに使う。
選んだ記録の原文・用途・感想を渡し、共通点、違い、不足している情報を比較画面へ返す。
他の人の記録は、共有が許可された範囲を使う。

比較結果と本人の判断は [分析・比較結果](../../01_DB/16_insights.json)へ保存する。
結果について相談する会話にも同じ比較を表示し、元の記録を開けるようにする。

### 地図の見た目を変える

アプリを育てる画面の地図カスタマイズで「夜でも水辺が見やすい地図にしたい」と頼む。
希望と現在の設定を渡し、変更案と説明を地図のプレビューへ返す。
本人が保存した時点で通常の地図へ反映する。

### 発見の説明を作る

場所・建物・写真の特徴から、関連する知識や別の見方を伝えるときに使う。
対象の特徴と説明の根拠を渡し、関連する説明と次の観察のきっかけを発見カードへ返す。
一般的な知識と、その対象で確認された事実を分けて説明する。

「気になる」「保存」「表示しない」は発見機能が記録する。
発見カードと反応は[根拠の保存](../03_information/03_evidence.md)へ保存する。
