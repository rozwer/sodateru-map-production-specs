# 場所・経路検索

場所の候補と道路経路を取得し、検索欄・投稿・相談・提案・拡張機能へ返す。

## 使途と結果の反映先

### 地図から場所の詳細を開く

検索欄に場所名・住所・駅名を入力するか、地図上の場所や建物を選ぶ。
入力文字や選択対象から場所を特定し、名前・住所・位置を場所詳細へ返す。
その場所を「ここへ行く」「ここでの体験を記録」「写真を投稿」へ引き継ぐ。

取得した基本情報は [場所](../../01_DB/01_places.json)として扱う。
本人の体験や他の人の投稿は [情報取得](../03_information/README.md)から同じ場所の詳細へ集める。

### AI相談の候補と道順を地図に出す

「近くのカフェを探して」という相談から、出発点と探す場所の種類を受け取る。
候補の名前・住所を会話へ、位置を地図へ返す。
候補を選んだら、その出発点と目的地で経路を取得し、距離・時間・道路に沿った線を表示する。

本番で後から開く道順は [保存ルート](../../01_DB/06_saved_routes.json)へつなぐ。
現在のローカル相談では、一時的な地図表示に使う。

### 体験や写真の投稿に場所を付ける

投稿画面から、場所名の検索や地図上の選択を行う。
選んだ場所を投稿の確認欄へ返し、本文・写真・公開範囲と一緒に確認する。
保存時は同じ場所を [記録](../../01_DB/02_records.json)と対応させる。

訪問履歴から写真を追加する場合は、元の訪問と場所を引き継ぐ。
同じ訪問への追加として保存する。

### 今日できる過ごし方を探す

今日の提案画面から、希望、使える時間、出発点、場所の条件を受け取る。
候補と移動時間を返し、提案機能が滞在時間も含めて条件に合うかを判断する。
「20分休みたい」なら、移動と滞在を合わせて使える時間に収まるかを確認する。

選択・あとで・見送りは [提案](../../01_DB/12_suggestions.json)へ保存する。
行くと決めた場所を案内へ渡し、達成は本人の訪問確認と対応させる。

### 別の街で同じ過ごし方を試す

体験を別の街へ移す画面から、残したい過ごし方と順序、移動先の地域、時間などを受け取る。
その地域の候補と地点間の移動時間を返し、「元の体験に忠実な案」「自分向けの案」の比較に使う。
本人が選んだ案を、その街の地図と案内へ渡す。

リハーサルには体験レシピ、候補取得、二方式の計画比較がある。
共通基盤は候補と区間の距離・時間を返す。残したい意味・条件と二方式の計画は体験移転機能が保持し、選択した地点列を経路取得へ渡す。

### バイクや聖地巡りで目的地を選ぶ

バイクでは施設名・住所・道路名、聖地巡りでは作品と対象地域・地点順を使う。
候補と道順を各拡張機能の一覧へ返し、選んだ場所を共通の地図に表示する。
車種ごとの通行条件と作品・場所の対応は、それぞれの拡張機能が判断する。

導入・設定は [プラグイン設定](../../01_DB/07_plugin_settings.json)、保存する道順は [保存ルート](../../01_DB/06_saved_routes.json)へつなぐ。
拡張機能を無効化したら、その機能の表示を地図から外す。
