## 実接続・画面での受入

1. 保存済みの名前を検索し、保存済み優先の順序を確認する。未登録名ではNominatimの有効行と出典を候補へ表示する。検索だけではplacesが増えない。
2. 候補を投稿へ採用し、同じ保存を再送する。場所は一件で、期限後の再送でも同じ場所を開ける。
3. Search Boxの周辺候補から徒歩経路を出す。形状を実際の道路と比較し、候補番号・名称・距離・時間が会話と地図で一致する。
4. storableの地点から経路を保存して再読込する。保存した形状・地点順・時間・取得時刻で再表示する。temporaryは保存時に再選択へ進む。
5. 429、NoRoute、タイムアウト、二番目の区間だけの失敗を発生させる。部分的な経路を完成として保存しない。
6. 390×844と1440×900で候補選択・詳細・閉じる・再試行・保存へ到達できる。プラグイン無効化ではその表示だけが消える。

要求条件・provider応答の取得時刻・候補ID・保存ID・再読込結果を証拠へ残す。
