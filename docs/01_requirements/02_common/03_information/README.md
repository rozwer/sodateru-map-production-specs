# 情報取得

画面が必要とする記録・投稿・施設・媒体・根拠を、同じ対象と閲覧範囲で読み出す。

## 使途と結果の反映先

### 場所詳細で施設情報と体験を読む

地図で選んだ場所を受け取り、施設情報、自分の体験、閲覧できる他の人の投稿を集める。
名前・住所・出典、本文・日時・写真などを、その場所の詳細へ返す。
記録や投稿の操作にも同じ場所を渡す。

### 日記・振り返りでその日の材料を読む

自分を知る画面から、本人と対象日を受け取る。
[訪問](../../01_DB/15_visits.json)、[記録](../../01_DB/02_records.json)、[媒体](../../01_DB/03_media.json)を読み、その日の一覧と日記の編集画面へ返す。
AI下書きを使う場合は、本人が対象にした記録を生成の材料にする。
本人が保存した日記は記録へ残す。

### 傾向の根拠を集める

傾向画面で選んだ期間と本人を受け取る。
期間内の訪問・記録・[その時点の回答](../../01_DB/11_self_checkins.json)を分析機能へ返し、集計と説明に使う。
グラフや説明から、根拠になった記録を開けるようにする。

保存する結果と根拠、本人の判断は [分析・比較結果](../../01_DB/16_insights.json)へつなぐ。
元の記録を訂正・削除したときは、参照している結果を再評価する。

### テーマや比較の対象を読む

テーマ編集や比較画面で、本人が選んだ記録を受け取る。
原文、場所、用途、感想を返し、共通点・違いの表示やテーマ名の編集に使う。
他の人との比較では、現在の共有範囲を確認してから取得する。

名前と所属記録は [テーマ](../../01_DB/13_themes.json)、保存する比較は [分析・比較結果](../../01_DB/16_insights.json)へつなぐ。
比較について相談する会話からも、同じ結果と元の記録を参照する。

### 今日の提案に使う条件を読む

今日の回答、本人の提案設定、候補の場所を受け取る。
希望、使える時間、提案を停止した活動、場所で確認できた条件を提案機能へ返す。
提案機能は、それらと移動時間を使って候補の適合を判断する。

結果と根拠、選択・保留・達成の状態は [提案](../../01_DB/12_suggestions.json)へつなぐ。
今日の回答が訂正された場合は、条件と理由を再評価する。

### 共有投稿を検索し、同じ結果を地図に出す

みんなで育てる画面から、場所・地域・本文・人の表示名と、目的・期間・距離・公開範囲の条件を受け取る。
閲覧できる投稿、投稿者、写真・動画、場所を返し、投稿一覧や人ごとの表示に使う。

「地図で見る」では、その検索結果の投稿と場所を地図へ渡す。
一覧へ戻るときも条件・選択・表示位置を引き継ぐ。
公開取消やフレンド関係の変更は、取得と再表示の際に反映する。

### 地域の声を読む・残す

地域の声の画面から、場所と話題を受け取る。
本人の投稿と閲覧できる共有投稿を集め、投稿者・日時・原文を「この場所で聞かれた声」へ返す。

本人が声を残す場合は、文章と公開範囲を確認して記録・共有の保存処理へ渡す。
音声を添付する場合も、本文と場所との対応を保つ。

### 発見カードの根拠を読む

選んだ場所・建物・写真と、その特徴を受け取る。
説明の根拠を発見機能へ返し、関連する知識や次の観察のきっかけをカードに表示する。
本人の「気になる」「保存」「表示しない」を同じカードに結び付ける。

発見カード・根拠・反応は[根拠の保存](03_evidence.md)の二表へ保存する。

### 拡張機能へ地域情報を渡す

バイク、聖地巡り、防災などの画面から、地域・車種・作品などの条件を受け取る。
道路情報、訪問先、地域情報を出典とともに返し、各機能の説明と地図表示に使う。

車種による通行条件、作品と場所の対応、防災情報の意味付けは各拡張機能が担当する。
その機能を無効化したときは、対応する表示を地図から外す。


## 実装する順序

| 文書 | 決めること |
|---|---|
| [取得と検索](01_queries.md) | 場所詳細、期間、共有検索、並び順とページ |
| [共有と媒体](02_access-media.md) | 閲覧判定、共有取消、媒体の取得と解放 |
| [根拠と更新](03_evidence.md) | 原文の版、分析の再利用、訂正・削除、発見 |
| [確認例](04_acceptance.md) | 日時・権限・101件目・遅着・取消 |
| [形式定義](schemas.json) | 入力条件、記録の読出し形式、部分失敗 |
| [検査データ](examples.json) | 保存データと期待する読出し結果 |

集計や候補順位は利用側の機能が計算する。
共通基盤は、対象と根拠を欠けずに返し、変更・削除を反映する。
