# 既定地域の公開規制根拠の不足（2026-09-15）

対象設定は渋谷周辺 `[139.69,35.65,139.73,35.69]`、250cc motorcycle、高速回避。共通ROUTES実取得は `[139.701,35.659]` → `[139.712,35.665]` の1,556.924m。道路名は神宮通り、玉川通り/国道246号、青山通り（金王坂）/国道246号。形状・時刻・高速回避評価は `live-route-scope.json` に保持した。全国取得基盤は追加していない。

| 根拠 | 補える条件 | 残る不足 |
|---|---|---|
| Mapbox / 共通ROUTES #25 | 同じ実取得の全区間で motorway 除外を要求し、違反通知・道路分類を検査 | 排気量・二輪通行規制は扱わない |
| OSM実取得 | 地点、明示された車種/一般アクセス規制、高速道路種別、object更新時刻 | タグ欠測、方向・時間等の追加条件、Mapbox各区間との一意対応。近傍道路を全区間許可に転用できない |
| 日本二輪車普及安全協会・東京都一覧 | 掲載された区間の車種・時間別禁止情報 | 対象3道路の選択形状全体に対応する車種許可の証拠は確認できない。未掲載は許可とは扱えない |

協会の[案内](https://www.jmpsa.or.jp/society/roadinfo/)は警察提供の情報を年次調査・更新すると説明し、現地標識の確認を求めている。[東京都一覧](https://www.jmpsa.or.jp/society/roadinfo/area-119-123.html)には千駄ヶ谷から新宿方面のトンネルで一般原付等を対象とする項目があるが、今回の神宮通り→国道246号の経路全体の通行許可にはならない。

[利用規約](https://www.jmpsa.or.jp/about/terms.html)は法定範囲を超える複製・転用等について事前の文書承諾を要求している。機械取得してアプリDBへ規制データとして保存・再配布できる許諾は確認できなかった。資料自体を取り込むadapterは作成せず、ここには分析と出典リンクだけを残す。

## 相談窓口に必要な条件

- 対象: 上記約1.56kmの選択経路全区間。moped / light_motorcycle / motorcycle / electric_motorcycle の区分と必要な排気量・出力条件。
- 機能: 時間・方向等も含む規制根拠を同じ経路形状へ対応付ける、または固有条件を満たす形状を共通ROUTESへ渡すこと。
- 保存: 評価時点・出典・geometry・車種設定をsnapshot保存し、再起動後にも同じ結果を表示できること。
- 利用時期: コンペ期間中に利用開始できること。特定の有償providerが必須とは断定しない。

上記の車種適合根拠は未取得。高速回避verified / 車種unknown / adoptable=false を維持し、BIKE.completeは未達。
