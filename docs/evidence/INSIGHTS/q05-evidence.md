# Q05 固定5軸の日別判定

2026-09-15、ユーザー決定: 自然/本/カフェ/散歩/人との時間。既存記録に明記された体験から判定。「本を見つけた」も本。新しい必須日別入力は追加しない。既存6軸periodAnswersは別の回答として保持する。

## 集計
実効日時が期間内に開始する記録をIANA日付へ割り当てる。複数日へ無条件複製しない。日時不明は判定に使わない。
明示体験がある日はyes。同日重複は1日。「今日は一日、散歩をしなかった」のような一日全体の明示否定のみno。部分行動の否定から軸全体をnoにしない。同日のyes/no矛盾は両根拠を保持し不明。
分子=yes日、分母=yes/no判断可能日。不明は分母から除外、分母0はnull。記録なしを0にしない。

## 原文判定の実装範囲
daily-evidence.tsの版付き定型表現で、完了した本人の体験文と保存済みactivitiesを読み取る。場所カテゴリやpurposeからは推定しない。願望、第三者の体験、対応していない自由文は不明として残す。自然文の包括的意味判定は未提供で、対象表現の拡充は後続要件。
本人文selfReports（引用・元recordId・sourceRefs）、観測observations、推定inferences、反例counterexamples、不明unknownを分離。2体験から人格や検証済み傾向を結論しない。provisionalNameは期間の暫定的な体験記録という名前に留める。

## 統計
確定訪問は期間内に開始したvisit ID単位。新しい場所は全確定履歴の最初の開始日を使い、日時不明の履歴がある場所は初回不明。
GPSは保存観測線の幾何距離。segment/breakBeforeで分断し、欠測の補間や歩数・健康距離への変換をしない。
